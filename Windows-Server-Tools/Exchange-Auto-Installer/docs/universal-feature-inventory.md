# Exchange Auto Installer universal feature inventory

This is the hand-written, fail-closed release inventory for the Exchange Auto Installer. It was first audited against commit `0c436de7b80f1950bcd7be430488f65a66f1ef2b` on 2026-08-13 and refreshed against the current candidate source after the guided settings/tools, security, test, documentation, icon, and packaging work. Source and focused tests are cited as implementation evidence only: they are not substitutes for a package interaction, capture, release, or deployed-site proof. A row remains blocking if any required evidence column is missing, partial, stale, mocked, untraceable to the final commit, or not exercised from the packaged application.

## Current candidate verification refresh

- `npm run lint`: 31 JavaScript files and 185 unique HTML identifiers.
- `npm run typecheck`: 14 CommonJS module contracts.
- `npm test`: 12 focused tests passed, including deliberate removal negative regressions.
- `npm run verify:inventory`: 55 hand-written inventory rows and all required evidence columns.
- `npm run verify:opencode-release`: official OpenCode 1.18.18 asset name, 60,504,740-byte size, and SHA-256 matched.
- `npm run build`, `npm run package`, and `npm run verify:package`: the candidate produced unsigned Squirrel output, exact `RELEASES` linkage, a full package, hashes, seven-size icon structure, and extracted executable icon/version evidence. A post-commit rebuild is still required before that package becomes final provenance.
- Real packaged interaction, runtime server installation, localization, complete universal features, real captures, landing-site proof, publication, and release evidence remain blocking unless a later row explicitly supplies them.
